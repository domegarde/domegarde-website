Drafts to review

Every page that is written but not yet public, what is missing from it and who has to read it. An internal page: it is not linked from the site and not in the sitemap.

Last updated: 17 October 2026

Internal page: not linked from the site and not in the sitemap.

Nothing on this page, or on the drafts it lists, is public. Every draft is hidden from search engines, left out of the sitemap and not linked from the site. The addresses only work if you have them.

How to review a draft

  1. Open a draft from the list below.
  2. Read the yellow box at the top. It lists what has to be checked before the page can go out.
  3. Every dashed box is a placeholder. It says what goes there, suggests what to write and says who has to provide it. Each one has a number (Placeholder 1, 2, 3 and so on) so you can refer to it.
  4. Each box ends with an Example, shown in a green box. Examples are invented so that every page reads as finished. They are not facts: replace each with the real thing, or delete it. Use the button at the top of a draft, "View as a finished page", to see the page with the examples as plain text and the guidance hidden.
  5. Send your changes to Claude as: the page name, the placeholder number and your text. For a pricing or wording decision, write the decision. You can also edit the text files in the blog-src folder yourself and ask Claude to rebuild the pages.
  6. When a page is ready, say so. Claude removes the draft marker, adds the links and rebuilds. A page becomes public only when you have asked for it.

Before anything goes public

  • A lawyer reads the substance of anything about the law, and Claudia reads the French.
  • Every personal fact about a founder comes from the founder. An example is never one.
  • The site refuses to publish a page that still has a placeholder, so an example cannot go live by accident.
  • The website stays hidden from search engines until launch day, whatever the state of a page.
