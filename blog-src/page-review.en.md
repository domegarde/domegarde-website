Nothing on this page, or on the drafts it lists, is public. Every draft is hidden from search engines, left out of the sitemap and not linked from the site. The addresses only work if you have them.

## How to review a draft

1. Open a draft from the list below.
2. Read the yellow box at the top. It lists what has to be checked before the page can go out.
3. Every dashed box is a **placeholder**. It says what goes there, suggests what to write and says who has to provide it. Each one has a number (Placeholder 1, 2, 3 and so on) so you can refer to it.
4. Send your changes to Claude as: the page name, the placeholder number and your text. For a pricing or wording decision, write the decision. You can also edit the text files in the `blog-src` folder yourself and ask Claude to rebuild the pages.
5. When a page is ready, say so. Claude removes the draft marker, adds the links and rebuilds. A page becomes public only when you have asked for it.

## Before anything goes public

- A lawyer reads the substance of anything about the law, and Claudia reads the French.
- Every personal fact about a founder comes from the founder.
- The website stays hidden from search engines until launch day, whatever the state of a page.
